# Claude Code Usage Viewer

Claude Code の使用実績をターミナルで視覚的に表示するPythonツール。`ccusage blocks --json` の出力を解析し、日別のタイムラインをアスキーアートで表現します。

## 特徴

- 📊 **タイムライン表示**: 24時間のタイムラインを48文字のアスキーアートで表現
- 🎨 **カラー表示**: 背景色でメジャーバージョン、その上に重ねた数字で小数点以下を表示（例: 赤背景の `8` = Opus-4.8、黄土背景の `5` = Opus-5.5）。背景色同士は知覚色差 ΔE≥34 ではっきり区別でき、同じメジャーの新バージョン（例: Fable 5.2）が出ても色が増えない
- 📈 **統計情報**: 総使用時間、コスト、トークン数などの統計
- 🔍 **フィルタリング**: 高使用日、高コスト日のみ表示
- 📋 **ソート機能**: コスト順、使用時間順でのソート
- 🚀 **リアルタイム情報**: 現在のセッション状態を1行で表示
- 🤖 **新モデル自動対応**: 将来の新しいClaudeモデルを自動認識・表示
- 🔍 **未知のモデル検出**: 未知のモデルが使用された場合、凡例に自動表示
- 🧾 **動的な凡例**: データに実際に含まれるモデルだけを色名つきで表示

## インストール

```bash
# リポジトリをクローン
git clone https://github.com/akiporoyopida/bb.git
cd bb

# 実行権限を付与
chmod +x b.py

# オプション: PATHに追加
cp b.py ~/bin/
# または
sudo cp b.py /usr/local/bin/
```

## 必要な環境

- Python 3.6以上
- [CC Usage](https://github.com/Aider-AI/aider) (Claude Code使用状況を取得するため)

## 使用方法

### 基本的な使用

```bash
# ccusageから直接パイプで入力
ccusage blocks --json | python3 b.py

# JSONファイルから読み込み
python3 b.py < blocks.json

# ファイルを指定
python3 b.py --file blocks.json
```

# 実行例
```bash
ccusage blocks --live --json | python3 claude_code_viewer.py --current
```

# アクティブな場合の出力例
```bash
● opus-4      $ 16.79       6,779,420/ 58,679,737    [ 11.6%] → 74.3% ($109.38) リセット: 15:00 (3h24m)
 [62エントリー] バーンレート: 183,414 tokens/分, $27.25/時間
```

# 非アクティブな場合の出力例  
```bash
○ opus-4      $  0.00               0/ 58,679,737    [  0.0%] リセット: 15:00 (3h24m) [0エントリー]
```

### 現在のセッション情報

```bash
# 現在の使用状況を1行で表示
ccusage blocks --json | python3 b.py --current

# 出力例:
# opus-4      $ 45.67      23,456,789/ 58,679,737    [ 40.0%] リセット: 15:00 (2h35m) [3セッション]
```

### フィルタリング

```bash
# 高使用日のみ表示（5時間以上）
ccusage blocks --json | python3 b.py --high-usage

# 高コスト日のみ表示（$50以上）
ccusage blocks --json | python3 b.py --high-cost
```

### ソートと表示制限

```bash
# コスト順で上位10日を表示
ccusage blocks --json | python3 b.py --sort-cost --limit 10

# 使用時間順で上位5日を表示
ccusage blocks --json | python3 b.py --sort-duration --limit 5
```

### 詳細情報

```bash
# 特定日の詳細を表示
ccusage blocks --json | python3 b.py --date 2025-09-13

# モデル別の統計を表示
ccusage blocks --json | python3 b.py --model-summary

# 統計情報のみ表示
ccusage blocks --json | python3 b.py --summary
```

### その他のオプション

```bash
# カラー表示を無効化（パイプやファイル出力用）
ccusage blocks --json | python3 b.py --no-color > report.txt

# 凡例を非表示
ccusage blocks --json | python3 b.py --no-legend

# ヘルプを表示
python3 b.py -h
```

### 凡例

#### モデル別の表示（背景色＋数字）

タイムラインの1マス（30分）は、**背景色＝メジャーバージョン**、**重ねた数字＝小数点以下**で表します。

| 表示例 | 意味 |
|---|---|
| 白背景に `1` | Fable-5.1 |
| 白背景に `2` | Fable-5.2 |
| 黄土背景に `5` | Opus-5.5 |
| 黄土背景に `0` | Opus-5 |
| 赤背景に `8` | Opus-4.8 |

数字の色は、背景とのコントラスト比が高い方（黒か白）が自動で選ばれます。凡例には**データに実際に含まれるモデルだけ**が表示されます（既知のモデルが1つもないデータでは、登録済みのメジャーバージョンを表示）。

| ファミリー | メジャー | 背景色 | 256色番号 |
|---|---|---|---|
| Fable | 5.x | 白 | 231 |
| Opus | 5.x | 黄土 | 136 |
| | 4.x | 赤 | 196 |
| | 3.x | 橙 | 208 |
| Sonnet | 5.x | 青 | 27 |
| | 4.x | 青緑 | 30 |
| | 3.x | 薄紫 | 141 |
| Haiku | 5.x | ピンク | 199 |
| | 4.x | 緑 | 40 |
| | 3.x | 薄緑 | 157 |

- 現行の7色（Fable 5 / Opus 5・4 / Sonnet 5・4 / Haiku 5・4）は、どの2色を比べても知覚色差 ΔE≥34
- 表にないメジャーバージョン（将来の Opus 6 など）は灰色（244）の背景で表示され、凡例に「未登録: 灰」と出ます
- `░` = **Synthetic** (グレー)
- `▒` = **複数モデル使用**（背景色は主要モデルのもの。優先度 fable > opus > sonnet > haiku、同じファミリー内では新しいバージョン）
- `◆` = **未知のモデル** (白) - 未知のファミリーが使用された場合に表示
- `·` = 使用なし
- `|` = 6時間マーカー（0, 6, 12, 18時）
- `--no-color` では背景色が消え、数字だけが表示されます

#### 新しいモデルの追加方法

同じメジャーの新バージョン（例: Fable 5.2、Opus 5.7）は**追加作業不要**です。背景色は共通で、数字が自動で変わります。

新しいメジャーバージョン（例: Opus 6）は、`b.py` の `MODEL_COLORS` に1行追加します。

```python
'opus-6':   (208, '橙'),
```

新しいファミリーを追加する場合は、さらに `_simplify_model_name` のファミリー一覧、`FAMILIES`、`BAR_CHARS`、`_pick_primary_model` の優先度にも追加が必要です。

#### コストの色分け
- 🟢 **緑**: コスト $20未満
- 🟡 **黄**: コスト $20-50
- 🔴 **赤**: コスト $50以上

## エイリアスの設定

よく使うコマンドは、シェルのエイリアスに設定すると便利です：

```bash
# ~/.zshrc または ~/.bashrc に追加
alias ccv='ccusage blocks --json | python3 ~/path/to/b.py'
alias ccv-current='ccv --current'
alias ccv-cost='ccv --sort-cost --limit 10'
alias ccv-today='ccv --date $(date +%Y-%m-%d)'
```

## トラブルシューティング

### `ccusage: command not found`
CC Usageがインストールされていません。[インストール手順](https://github.com/Aider-AI/aider)を参照してください。

### 文字化けする場合
```bash
# ロケールを設定
export LANG=ja_JP.UTF-8
export LC_ALL=ja_JP.UTF-8
```

### カラー表示されない場合
```bash
# ターミナルが256色対応か確認
tput colors

# 強制的にカラー表示を有効化
export TERM=xterm-256color
```

## 更新履歴

### v2.5.0 (2026-11-10)
- 🎨 **表示方式を変更: 背景色＝メジャーバージョン、数字＝小数点以下**
  - 例: Opus 4.8 は赤背景に `8`、Opus 5.5 は黄土背景に `5`
  - バージョンごとに文字色を割り当てる方式では、モデルが増えるたびに見分けやすい色が足りなくなっていたため変更
  - 背景色はメジャーバージョンごとの7色で、どの2色を比べても知覚色差 ΔE≥34（従来は ΔE≥23）
  - 数字の色は、背景とのコントラスト比が高い方（黒か白）を自動で選択
  - `--no-color` でも数字でバージョンを区別できる
- 🆕 **最新モデル対応（Haiku 5.5 / Fable 5.2）**
  - **Haiku 5.5** (`claude-haiku-5-5`): ピンク背景に `5`（Haiku 4.5 の緑背景と区別）
  - **Fable 5.2** (`claude-fable-5-2`): 白背景に `2`（同じメジャーなので追加作業なしで対応）
- 週間制限のモデル別内訳も、同じ背景色＋数字の見本つきで表示

### v2.4.0 (2026-09-23)
- 🆕 **最新モデル対応（Fable 5.1 / Opus 5.5）**
  - **Fable 5.1** (`claude-fable-5-1`): 青緑 (256色: 36) — Fable 5 の白と明確に区別
  - **Opus 5.5** (`claude-opus-5-5`): 薄ピンク (256色: 219) — Opus 5 の黄と明確に区別
  - 従来は Fable 5.1 が Fable 5 と、Opus 5.5 が Opus 5 と同じ色になっていた
- 🎨 **色の識別性を定量的に保証**
  - 実データに現れる全12モデルの知覚色差 (CIEDE2000) が最小 ΔE≈23 以上になるよう選定
  - **Sonnet 4.5**: シアン (端末色96) → オリーブ (64)。Sonnet 4.6 のシアン (51) と実質同じ色だった
  - **Opus 4.7**: ローズ 205 → 204（わずかに赤寄り。Opus 5.5 の薄ピンクと区別）
- 🧾 **凡例をデータに含まれるモデルだけの表示に**（色名つき）。表にない将来のモデルは「未登録」と表示
- 🛠 **色設定を `MODEL_COLORS` の1つの表に集約**。判定を完全一致にし、`opus-5` が `opus-5.5` を奪うような判定順の問題を解消
- 🐛 **モデル名解析の修正**
  - `claude-opus-4-20250514` のような日付サフィックスを誤ってマイナーバージョンと読んでいた問題を修正（→ `opus-4.0`）
  - 旧形式 `claude-3-5-sonnet-20241022` を `sonnet-3.5` として認識
  - 1つのブロックに同じファミリーの複数バージョン（例: Opus 4.8 と Opus 5）があると、実行のたびに `▒` の色が変わっていた問題を修正（新しいバージョンの色に固定）。`--current` の表示モデルも同じ優先度で決定（synthetic は除外）

### v2.3.0 (2026-06-10)

  - **Fable 5** (`claude-fable-5`): 太字の白 — 有彩色を使う他モデルと絶対に混ざらない無彩色を採用
  - **Opus 5** (`claude-opus-5`): 黄 (256色: 226) — 橙 (4.5) や赤系と明確に区別
  - **Sonnet 5** (`claude-sonnet-5`): 青 (256色: 33) — シアン (4.6) と明確に区別
  - モデル優先度を fable > opus > sonnet > haiku に更新
  - 凡例に新モデルを追加
- 🎨 **色の識別性改善（はっきり区別できる配色に）**
  - **Opus 4.7**: ローズピンク (256色: 205) に変更し、赤 (4.6) との見分けを改善
  - **Haiku 4.5**: 黄緑 (118) → 純緑 (46) に変更し、Opus 5 の黄と区別
